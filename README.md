# Codveda Internship - Task 3

## Basic DOM Manipulation - Counter Application

This project was created as part of the Codveda Technologies
Front End Development Internship.

Task 3 focuses on basic DOM manipulation using vanilla JavaScript.

The application is a simple interactive counter with increment,
decrement, and reset functionality.

---

## Task Requirements

The project implements:

- Basic DOM manipulation
- Dynamic DOM updates
- Increment button
- Decrement button
- Reset button
- Current count display
- JavaScript event listeners
- Prevention of negative values
- Minimalistic user interface
- Responsive design

---

## Features

### Increment

The increment button increases the counter by 1.
